# DaVinci Resolve MCP tools

Generated by scripts/gen_tools_doc.py — do not edit.

## Read tools

These tools only read state. They never change the project.

### get_clip_properties

read-only, idempotent

Get the properties, metadata and marker count of one media pool clip, found by id (preferred, whole pool) or by name (current folder first, then whole pool). Provide name or id. Returns a curated set of clip properties (type, codec, fps, timecodes, color, flags and more) as strings exactly as Resolve reports them, plus the clip metadata table. metadata is Resolve's full metadata table for the clip (user-entered fields, unfiltered).

| Argument | Type | Required | Constraints | Description |
|---|---|---|---|---|
| `name` | string | no | maxLength 500 | Clip name (use id when names repeat). |
| `id` | string | no | maxLength 100 | Clip unique id from list_media_pool. |

### get_project_info

read-only, idempotent

Summarize the open project: name, timeline frame rate and resolution (strings as Resolve stores them), timeline names, current timeline, queued render job count and current page.

No arguments.

### get_project_setting

read-only, idempotent

Read one project setting by key (for example timelineFrameRate or timelineResolutionWidth), or every setting when no key is given. Values are strings exactly as Resolve returns them; the full list is large.

| Argument | Type | Required | Constraints | Description |
|---|---|---|---|---|
| `key` | string | no | maxLength 100 | Setting key. Omit to return all settings. |

### get_render_status

read-only, idempotent

List the render queue of the current project with each job's status, completion percentage, error and timing (milliseconds), plus whether Resolve is rendering right now. Poll this after start_render.

No arguments.

### get_timeline_info

read-only, idempotent

Describe a timeline (default: current): name, start/current timecode, frames, frame rate, track counts and marker count. Two frame spaces exist: startFrame/endFrame, markers and timecodes use ABSOLUTE timeline frames (a 24 fps timeline starting at 01:00:00:00 has startFrame 86400); timeline item start/end are absolute on Resolve 21.1 but were 0-based offsets on older builds, so prefer the startAbs/endAbs fields of get_timeline_items.

| Argument | Type | Required | Constraints | Description |
|---|---|---|---|---|
| `timeline` | string | no | maxLength 200 | Timeline name. Omit to use the current timeline. |

### get_timeline_items

read-only, idempotent

List the items on one track of a timeline (default: current), paged (limit 1-200, default 50). start/end are as Resolve reports them (absolute frames on 21.1, 0-based offsets on older builds); startAbs/endAbs are normalised absolute timeline frames usable for markers and timecodes. index is the 1-based position on the track (use it with delete_timeline_items). Returns {timeline, track, total, offset, limit, truncated, items}.

| Argument | Type | Required | Constraints | Description |
|---|---|---|---|---|
| `trackType` | string | yes | one of `video`, `audio`, `subtitle` | Track type. |
| `trackIndex` | integer | yes | min 1 | 1-based track number. |
| `offset` | integer | no | min 0 | Items to skip (default 0). |
| `limit` | integer | no | min 1; max 200 | Max items to return (default 50). |
| `timeline` | string | no | maxLength 200 | Timeline name. Omit to use the current timeline. |

### get_timeline_markers

read-only, idempotent

List the markers of a timeline (default: current) sorted by frame, paginated with offset/limit (max 200). Marker frames are ABSOLUTE timeline frames. Returns {timeline, total, offset, limit, truncated, markers:[{frame, color, name, note, duration, customData}]}.

| Argument | Type | Required | Constraints | Description |
|---|---|---|---|---|
| `timeline` | string | no | maxLength 200 | Timeline name. Omit to use the current timeline. |
| `offset` | integer | no | min 0 | Skip this many markers (default 0). |
| `limit` | integer | no | min 1; max 200 | Markers per page (default 50). |

### list_media_pool

| Argument | Type | Required | Constraints | Description |
|---|---|---|---|---|
| `folder` | string | no | maxLength 500 | Slash path to a media pool folder, e.g. "Master/B-roll" ("Master" or "/" is the root; a leading "Master/" is optional). Default: the root folder. |
| `offset` | integer | no | min 0 | Clips to skip (default 0). |
| `limit` | integer | no | min 1; max 200 | Maximum clips to return (default 50). |

### resolve_status

read-only, idempotent

Report whether the Resolve bridge is running and what Resolve is doing (edition, version, current page, project and timeline). This is the first call to make in any session. ## Write tools

### add_marker

write, not idempotent

Add a marker at an ABSOLUTE timeline frame (see get_timeline_info for startFrame). The frame must be strictly after the timeline start frame and before the end frame, on clip content, with no existing marker. Duration is in frames (default 1). Returns {ok, frame, color, name}.

| Argument | Type | Required | Constraints | Description |
|---|---|---|---|---|
| `frame` | integer | yes | min 0 | Absolute timeline frame for the marker. |
| `color` | string | yes | one of `Blue`, `Cyan`, `Green`, `Yellow`, `Red`, `Pink`, `Purple`, `Fuchsia`, `Rose`, `Lavender`, `Sky`, `Mint`, `Lemon`, `Sand`, `Cocoa`, `Cream` | Marker color. |
| `name` | string | no | maxLength 200 | Marker name (default empty). |
| `note` | string | no | maxLength 2000 | Marker note (default empty). |
| `duration` | integer | no | min 1; max 100000 | Duration in frames (default 1). |
| `customData` | string | no | maxLength 200 | Custom data string (default empty). |
| `timeline` | string | no | maxLength 200 | Timeline name. Omit to use the current timeline. |

### add_render_job

write, not idempotent

Queue a render job for the current (or a named) timeline into an existing absolute folder, optionally applying a render preset, a format and codec, and a mark-in/mark-out range in absolute timeline frames. Non-blocking: follow with start_render and poll get_render_status.

| Argument | Type | Required | Constraints | Description |
|---|---|---|---|---|
| `targetDir` | string | yes | minLength 1; maxLength 1000 | Absolute path of an existing folder to render into. |
| `customName` | string | no | maxLength 200 | Output file name without extension (default: Resolve's own name). |
| `preset` | string | no | maxLength 100 | Render preset name to load first (see list_render_options). |
| `format` | string | no | maxLength 60 | Render format name, for example 'mp4' (see list_render_options). |
| `codec` | string | no | maxLength 60 | Codec value for the format; requires format. Default: the format's first codec. |
| `markIn` | integer | no | min 0 | First frame to render, absolute timeline frame (a 01:00:00:00 timeline at 24 fps starts at 86400). |
| `markOut` | integer | no | min 0 | Last frame to render, absolute timeline frame. |
| `timeline` | string | no | maxLength 200 | Timeline name to render; it becomes the current timeline. Default: the current timeline. |

### delete_timeline_items

DESTRUCTIVE, not idempotent

Delete items from one track by their 1-based positions as returned by get_timeline_items (up to 50). Pass expectedNames (same order) so the delete is refused if the track changed since you listed it. Non-ripple: leaves gaps. Irreversible except via Resolve's own Undo. Requires confirm:true after the user agreed. Returns {ok, deleted, remaining}.

| Argument | Type | Required | Constraints | Description |
|---|---|---|---|---|
| `confirm` | boolean | yes | one of `true` | Must be true to confirm this irreversible action. |
| `trackType` | string | yes | one of `video`, `audio`, `subtitle` | Track type. |
| `trackIndex` | integer | yes | min 1 | 1-based track number. |
| `itemIndexes` | array | yes | minItems 1; maxItems 50; items: integer (min 1) | 1-based item positions on the track, as returned by get_timeline_items. |
| `expectedNames` | array | no | maxItems 50; items: string (maxLength 500) | Item names in the same order as itemIndexes; the delete is refused on any mismatch. |
| `timeline` | string | no | maxLength 200 | Timeline name. Omit to use the current timeline. |

## Open-ended

This tool can run any Lua against the open project. Read first and ask before destructive changes.

### run_lua

DESTRUCTIVE, not idempotent

Run a Lua 5.1 chunk inside DaVinci Resolve and return its first return value (tables become JSON) plus captured print() output. Bound names: resolve, fusion, projectManager, project (current or nil), timeline (current or nil), mediaPool, bmd. The API is Blackmagic's scripting API (look signatures up with scripting_api_docs) with colon calls and 1-based lists, e.g. timeline:GetItemListInTrack("video", 1). Open-ended: it can modify or delete anything in the open project, so read first and ask before destructive changes. Avoid Studio-only calls on the free edition (they fail or open an upgrade dialog that blocks the bridge). Long calls block the bridge until they finish; raise timeout_s for them. The timeout is enforced by the server only: a chunk that never returns (an unbounded loop, a modal dialog) blocks the bridge until Resolve is restarted, so keep loops bounded. Set DAVINCI_MCP_DISABLE_RUN_LUA=1 in the server environment to remove this tool.

| Argument | Type | Required | Constraints | Description |
|---|---|---|---|---|
| `code` | string | yes | minLength 1; maxLength 49152 | Lua 5.1 source. Use `return <value>` to get data back. |
| `timeout_s` | integer | no | min 1; max 600 | Seconds to wait for the chunk (default 30). |
| `max_kb` | integer | no | min 1; max 256 | Result size cap in KB (default 64); larger results return truncated with a preview. |
